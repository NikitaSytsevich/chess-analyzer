# Наборы фигур

Фигуры взяты из [lichess-org/lila](https://github.com/lichess-org/lila/tree/master/public/piece)
без изменений. Распознаватель рисует из них шаблоны под размер клетки, а интерфейс — доску.

авторским правом и в проект не входят: распознаватель выучивает их сам по трансляции.
