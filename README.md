# Шахматный анализатор

Суфлёр комментатора шахматных трансляций. Анализатор смотрит в окно с видео
(Lichess, Chess.com), находит на нём доску, следит за партией ход за ходом и
в реальном времени показывает оценку Stockfish 19, шансы сторон, лучшие
продолжения, ошибки и «единственные ходы». Подсказки видит только
комментатор — в эфир они не попадают.

Написан на Rust; интерфейс — [GPUI](https://github.com/zed-industries/zed)
(из редактора Zed), движок — [Stockfish 19](https://stockfishchess.org).

## Системы

| Система | Что работает |
|---|---|
| macOS 15+, Apple Silicon | всё: захват окна трансляции, распознавание, анализ |
| Windows 10 (1903+) и 11 | всё: захват окна трансляции, распознавание, анализ |

## Windows

### Готовая сборка

GitHub → вкладка **Actions** → последний запуск **CI** → артефакт
**chess-analyzer-windows-x64**. В архиве — папка приложения: распакуйте её
куда угодно и запустите `Шахматный анализатор.exe`.

Сборка не подписана, поэтому Windows при первом запуске может показать
«Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом
случае».

### Сборка из исходников

1. **Visual Studio Build Tools 2022** —
   <https://visualstudio.microsoft.com/visual-cpp-build-tools/>. В установщике
   отметьте «Разработка классических приложений на C++»: в неё входят
   компилятор MSVC и Windows SDK (из SDK берётся компилятор шейдеров `fxc.exe`).
2. **Rust** — <https://rustup.rs>, файл `rustup-init.exe`, установка по
   умолчанию. Нужную версию Rust проект поставит сам.
3. **Git** — <https://git-scm.com/download/win>.
4. Скачайте проект в короткий путь без пробелов — у Windows есть предел длины
   пути, а сборка GPUI создаёт глубокие папки:

   ```powershell
   git clone https://github.com/NikitaSytsevich/chess-analyzer C:\dev\chess-analyzer
   cd C:\dev\chess-analyzer
   ```

5. Соберите и запустите:

   ```powershell
   cargo xtask run --release
   ```

   Первая сборка идёт 10–20 минут. Команда сама скачает Stockfish 19 (78 МБ,
   с проверкой контрольной суммы) и запустит приложение. Готовая папка —
   `target\release\Шахматный анализатор\`, её можно копировать куда угодно.

На экране приветствия нажмите «Выбрать окно трансляции»: Windows покажет
список окон — выберите окно браузера или плеера. Прав и настроек не нужно.
Пока окно захватывается, Windows обводит его жёлтой рамкой; рамку видите
только вы, на Windows 11 анализатор просит её не рисовать.

Без трансляции нажмите «Посмотреть на демо-партии»: «Оперная партия» 1858
года пройдёт через распознавание, слежение за ходами и Stockfish.

## macOS

Нужны Command Line Tools (`xcode-select --install`) и Rust
(<https://rustup.rs>). Xcode не нужен.

```sh
cargo xtask run
```

Команда скачает Stockfish, соберёт «Шахматный анализатор.app» в `target/` и
запустит его. Окно трансляции выбирается в системном окне macOS —
разрешение «Запись экрана» не понадобится.

## Клавиши

| Клавиша | Действие |
|---|---|
| Пробел | пауза анализа |
| F | перевернуть доску |
| R | найти доску заново |
| I | только доска / доска с панелью анализа |
| T | поверх всех окон |
| ⌘O / Ctrl+O | выбрать другое окно трансляции |
| ⌘C / Ctrl+C | скопировать позицию (FEN) |
| ⇧⌘C / Ctrl+Shift+C | скопировать партию (PGN с оценками) |
| ⌘V / Ctrl+V | задать позицию из FEN |

## Устройство

```
crates/
  chess     партия, нотация (русская и английская), оценки, классы ходов, PGN
  engine    Stockfish по UCI: отдельный поток, троттлинг, перезапуск при падении
  vision    поиск доски на кадре, распознавание фигур, обучение незнакомым наборам
  tracker   ход за ходом по потоку распознанных досок: откаты, смена партии
  capture   захват окна трансляции (macOS — ScreenCaptureKit, Windows — Windows.Graphics.Capture)
  session   всё вместе: кадры → партия → анализ → подсказки
  app       окно на GPUI
  cli       тот же конвейер в терминале: `cargo run -p analyzer-cli -- demo`
xtask/      загрузка Stockfish, иконка (`cargo xtask icons` из assets/icon/icon.svg),
            упаковка приложения, проверки
```

Ядро (всё, кроме `app` и `capture`) не зависит ни от системы, ни от
интерфейса и проверяется тестами. Проверки перед коммитом: `cargo xtask ci`.
